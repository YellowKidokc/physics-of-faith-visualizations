A comprehensive gallery showcasing the intersection of physics and faith through mathematical visualizations and academic papers.

- **THEOPHYSICS** - Core framework visualizations and academic papers
- **12 Laws** - Devotional content and spiritual principles
- **13 Theses** - Academic research papers on consciousness and physics

## 📊 Gallery Features

- **437+ Visualizations** - High-quality images and interactive diagrams
- **Featured Collections** - Curated sets with detailed explanations
- **Modal Viewer** - Full-screen image viewing with metadata
- **Download with Watermark** - PNG downloads with attribution
- **Share Functionality** - Generate shareable links
- **Search & Filter** - Find specific visualizations by tags or keywords

## 🚀 Quick Start

1. **View Gallery**: Open `index.html` in your browser
2. **Add Images**: Drop images into `/images/` folder
3. **Create Collections**: Add folders to `/collections/` with `index.html`
4. **Build**: Run `python build.py` to update gallery
5. **Deploy**: Use `auto-deploy.bat` for automated deployment
