## 🏷️ **TAG CATEGORIES**

### **1. STATUS TAGS**

**Completion Status:**
- `#complete` - Finished and ready for publication
- `#draft` - In progress, substantial work done
- `#outline` - Framework defined, content needed
- `#planned` - On roadmap, not started
- `#archived` - Historical reference, superseded

**Validation Status:**
- `#validated` - Confirmed by Master Equation
- `#partial-validation` - Some elements confirmed
- `#needs-validation` - Requires verification
- `#experimental` - Speculative, needs testing

**Review Status:**
- `#peer-reviewed` - Externally reviewed
- `#internal-review` - Self-reviewed

## 🔍 **TAG USAGE GUIDE**

### **When Creating New Document:**

**1. Assign Core Tags:**
```markdown
Tags: #[status] #[type] #[subject]
```

**2. Add Framework Tags:**
```markdown
Framework: #[thesis-X] #[core-concept]
```

**3. Set Priority:**
```markdown
Priority: #priority-[level]
Timeline: #release-[date]
```

**4. Note Dependencies:**
```markdown
Depends: #depends-[requirement]
Needs: #needs-[resource]
```

### **Example: New Paper Draft**

```markdown
# Paper #X: Title

**Tags:** #draft #paper #thesis-X #cosmology #information-theory
**Framework:** #logos-field #master-equation #coherence
**Priority:** #priority-medium #release-2026
**Dependencies:** #depends-paper-1 #depends-master-eq
**Needs:** #needs-grok #needs-visualization #needs-math-rendering
**Status:** #needs-validation #needs-review
```
